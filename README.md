## ⚡ Four Live Applications

1. **[Himachal Pradesh SDG Tracker & E-Waste Dashboard](https://himachalpradesh-sdg-tracker.lovable.app/)**
   - Interactive spatial and regulatory monitoring dashboard tracking e-waste metrics, authorized collection centers, and UN Sustainable Development Goal (SDG) alignment across Himachal Pradesh districts.
2. **[E-Waste EPR Compliance & Target Calculator](https://rj42-coder.github.io/e-waste-epr-calculator/)**
   - Web application implementing CPCB formula for calculating electronics manufacturers' Extended Producer Responsibility (EPR) targets, recycling quotas, and compliance credits under E-Waste Rules 2022.
3. **[ChainGuard — DeFi Anomaly & Threat Detection](https://github.com/Shubhiii92/ChainGuard)**
   - AI/ML transaction anomaly detection prototype developed during the SPIT 24-Hour Hackathon. Evaluates on-chain behavior and assigns real-time risk scores on Sepolia testnet using Random Forest and Isolation Forest.
4. **[Kids Car Game — Interactive 2D Driving Simulation](https://shubhiii92.github.io/kids-car-game/)**
   - Responsive 2D browser-based canvas obstacle driving game featuring real-time collision detection, continuous animation loops, and multi-device keyboard/touch controls.
